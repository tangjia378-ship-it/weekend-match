# Weekend Match - 周末搭子

大学生周末兼职匹配平台

## 项目简介

「周末搭子」是一个专为大学生设计的周末兼职匹配平台，帮助学生根据空闲时间、期望薪资和距离智能匹配合适的兼职机会，同时帮助校园周边商家快速发布短期用工需求。

## 技术栈

- **React 18** - 用户界面库
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **Tailwind CSS** - 样式方案
- **Lucide React** - 图标库

## 本地开发

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览构建结果

```bash
npm run preview
```

## 部署

项目已配置 GitHub Pages 部署，构建后的文件位于 `dist` 目录。

## 功能特性

- 🎯 智能匹配：根据时间、距离、薪资智能推荐
- 👥 双端模式：学生端和商家端自由切换
- 📱 响应式设计：完美适配移动端和桌面端
- 🎨 现代 UI：清新明亮的设计风格
- ⚡ 高性能：基于 Vite 的快速构建
